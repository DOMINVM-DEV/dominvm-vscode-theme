## ✦ Design Principles

### Zero Glare

All backgrounds use color-tinted hues — never pure white or pure black. This eliminates the harsh glare that causes eye strain during prolonged use.

### WCAG AA Compliant

Every syntax token achieves ≥ 4.5:1 contrast ratio against its background. Comment colors deliberately sit at 3.8–5.1:1 to visually recede while remaining readable.

### Three Depth Levels

| Variant | Background Luminance | Contrast Ratio | Best For |
|---------|---------------------|---------------|----------|
| **Light** | L ≈ 95–97 | 10–14:1 | Bright environments |
| **Dark** | L ≈ 3–5 | 10–12:1 | Low-light coding |
| **Dark Solarized** | L ≈ 8–12 | 8–10:1 | Extended sessions |

### Complete Token Coverage

Every theme defines **239 color tokens** — no fallbacks to VS Code defaults:

- ✅ Full terminal ANSI palette (20 colors)
- ✅ Git decoration colors (modified, deleted, untracked, ignored, conflict, added, submodule)
- ✅ Breadcrumb navigation styling
- ✅ Notification center with error/warning/info icons
- ✅ Minimap and overview ruler indicators
- ✅ Inlay hint (LSP) styling
- ✅ Sticky scroll headers
- ✅ Merge conflict markers
- ✅ Debug toolbar and console
- ✅ Settings editor styling

12 semantic token categories ensure consistent visual structure across all languages:

| · | Category | Purpose |
|---|----------|---------|
| 💬 | **Comments** | Annotations & documentation |
| 🔑 | **Keywords** | Language constructs (`if`, `return`, `export`) |
| 📝 | **Strings** | Text literals and templates |
| ⚡ | **Functions** | Callable entities and methods |
| 🏗️ | **Classes & Types** | Type definitions and interfaces |
| 📦 | **Variables** | Data references and parameters |
| 🔢 | **Constants** | Numeric values and language constants |
| 🔗 | **Properties** | Object keys and CSS properties |
| ⚙️ | **Operators** | Symbols and punctuation |
| 📌 | **Headers** | Markdown headings and sections |
| ✍️ | **Markup** | Bold, italic, and rich text |
| 🔍 | **Regex & Escapes** | Pattern matching and escape sequences |
